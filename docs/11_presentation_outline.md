# 5-Minute Presentation Outline

## Slide 1: Title and problem statement
- Project: UHG Claims Operations Assistant
- Problem: manual, fragmented claims operations with limited visibility and auditability

## Slide 2: Why this matters
- Volume and complexity of claims intake and approvals
- Need for operational efficiency, consistency, and safety
- Healthcare context requires trust and human oversight

## Slide 3: System architecture
- Streamlit UI
- Case store and business logic
- LangGraph workflow
- Security layer
- Evaluation and dashboard layer

## Slide 4: Workflow and user journey
- Register case
- validate and secure data
- review and summarize case
- route for human approval
- log outcomes and update metrics

## Slide 5: Key design decisions
- human-in-the-loop review
- safety and PII controls
- auditability
- evaluation gate and operational metrics

## Slide 6: Results and value
- improved workflow clarity
- safer handling of sensitive data
- measurable release readiness
- strong fit for real-world FDE-style engineering work

## Slide 7: Closing message
- This system demonstrates applied engineering thinking, governance, and measurable value.
- It is structured to show a credible path from prototype to production-ready operations tool.
